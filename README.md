# FACHS_DementiaBiomarker
R code used to run regression models in Cross-sectional and Longitudinal groups: [Cross-sectional_code.R](https://github.com/lw35327/FACHS_DementiaBiomarker/blob/main/Cross-sectional_code.R) and [Longitudinal_code.R](https://github.com/lw35327/FACHS_DementiaBiomarker/blob/main/Longitudinal_code.R).

R code used to generate main figures: [Plotting_Fig1and2.R](https://github.com/lw35327/FACHS_DementiaBiomarker/blob/main/Plotting_Fig1and2.R).

R code used to extract APOE genotype in our cohort: [ExtractAPOEgeno.R](https://github.com/lw35327/FACHS_DementiaBiomarker/blob/main/ExtractAPOEgeno.R).

R code used to calculate relatedness of individuals and remove related individuals for regression analysis:[remove_kinship.R](https://github.com/lw35327/FACHS_DementiaBiomarker/blob/main/remove_kinship.R).
